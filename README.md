📧 Automatización de Correos con Python

Aplicación desarrollada en Python para automatizar el envío de correos electrónicos personalizados a partir de un archivo Excel.

Funcionalidades

- Carga de clientes desde Excel.
- Visualización de datos.
- Generación de reportes personalizados.
- Envío automático de correos.
- Adjuntos automáticos.
- Reporte general de envíos.
- Interfaz web con Streamlit.

Tecnologías

- Python
- Pandas
- Streamlit
- SMTP
- OpenPyXL

Flujo

1. Cargar archivo Excel.
2. Revisar clientes.
3. Enviar correos.
4. Generar reportes.
5. Descargar reporte final.
